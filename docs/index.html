Find the program that is quietly wearing out your SSD.

Some programs write the same small file over and over, thousands of times an hour. Nothing looks wrong, but the drive inside your PC gets used up faster than it should. writehawk finds that, for free.

What is the problem?

The drive in your computer (the SSD) is like a notebook. Every spot on the page can only be written and erased so many times before it wears thin. That is normal, and a healthy PC takes many years to get there.

A buggy program can get stuck writing the same note in the same spot, again and again, all day. You cannot see it or hear it. That is the thing writehawk looks for.

Is this real?

Yes. In November 2026 it was reported for graphics card software from both NVIDIA and AMD. Both companies have released fixes since.

Is my PC broken?

Almost certainly not. This is about wear over months, not sudden damage. It is worth a five minute check, not a panic.

Is writehawk safe?

The check only looks. It changes nothing on your PC, sends nothing to the internet, and never reads what is inside your files.

Check your PC in 5 steps

About five minutes. You need a Windows 10 or Windows 11 PC and an internet connection.

Under 18, or not your own PC? Ask the adult who looks after the computer before you install anything. Show them this page.

  1. Open the Terminal

    Press the Windows key, type terminal, and press Enter. A dark window with a blinking cursor opens. That is where you will type.

    No "Terminal" on Windows 10? Type powershell instead. It works the same way.

  2. Get Python

    writehawk is written in a language called Python, so the PC needs Python first. Type this and press Enter:

    python

    If the Microsoft Store opens, click Get and wait until it finishes. Then close the Terminal and open it again (step 1).

    If you see >>> instead, Python is already there. Type exit() and press Enter.

  3. Install writehawk

    Copy this line, paste it into the Terminal (right-click pastes), and press Enter:

    python -m pip install https://github.com/BiosSystem/writehawk/archive/refs/heads/master.zip

    Wait until you see "Successfully installed writehawk". It takes under a minute.

  4. Run the check

    Type this and press Enter, then wait about 20 seconds:

    python -m writehawk scan

  5. Read the answer

    You will see a few lines for each known problem. Look for the word in CAPITAL LETTERS at the end of the first line, and find it in the list below.

What the answer means

NOT APPLICABLE  ·  FIXED  ·  NOT AFFECTED

You are fine. Either your PC does not have that kind of graphics card, or its software already has the fix. Nothing to do.

MITIGATED

Your software still has the bug, but someone has already switched off the part that causes it. You are protected. Updating the graphics driver is still a good idea.

EXPOSED  ·  VERSION UNKNOWN

Your graphics software is a version that has the bug. It was not seen writing during the check, but it can start. Update the graphics driver (see below).

ACTIVE

It is happening right now. Update the graphics driver today. Your files are safe; this is about wear, not about losing data.

How to fix it

The real fix is a newer graphics driver from the company that made your graphics card. writehawk tells you which company and which version in its answer.

NVIDIA (GeForce)

Get the newest driver from nvidia.com/drivers. The fix first came as a separate "hotfix" download, which is why the normal update button may not have offered it.

AMD (Radeon)

Get the newest driver from amd.com/support. Choose the newest version, even if it is marked "Optional".

After updating and restarting, run step 4 again. The answer should now say FIXED.

Cannot update right now? writehawk can switch off the faulty part for you and switch it back on later. That needs an administrator and a little more care, so it lives in the .

Questions people ask

It says "python is not recognized"

Python is not installed yet, or the Terminal was open while it installed. Do step 2 again, then close the Terminal and open a new one.

Does it cost anything?

No. It is free and open source. Anyone can read the code.

How do I remove it?

Type python -m pip uninstall writehawk in the Terminal. The check itself leaves nothing behind.

I do not have NVIDIA or AMD

Then the two known problems cannot affect you, and the check will say so.

writehawk scan needs no administrator rights. For every cause it knows, it says whether you have the hardware, whether your driver has the fix, and whether the writes are happening now.

> writehawk scan

nvidia-nvtopps-log-rewrite: EXPOSED
  NVIDIA display container rewrites its log file without pause
  Example GeForce card: driver 621.24 (affected from 621.14, fixed in 621.35)
  workaround: available, not documented by the vendor
  why the fix may not have reached this machine:
    - The fix is a hotfix driver. It has to be downloaded and installed by hand.

amd-eeu-dump-files: NOT APPLICABLE
  no amd display adapter in this machine

From an administrator terminal the scan also traces file writes for its duration, measures the loop, and lists rewrite loops that no known cause explains.

What it does

01 MEASURE

Sees rewrites, not just bytes

Counts how often each file is written over the same bytes, and how much of that is flushed to the drive. That separates a harmless loop from a harmful one.

02 EXPLAIN

Names the cause

Matches what it sees against a catalog of known bugs, each with its sources, and tells you which driver version fixes it and why that version may not have reached you.

03 ACT

Fixes, with an undo

Shows the exact registry values a workaround would change. Applies them only with --apply, after recording the prior state, and rollback puts everything back.

Commands

writehawk scan                  # known causes: affected, fixed, mitigated or writing now
writehawk top --seconds 5       # processes ranked by write rate
writehawk trace --seconds 15    # files by bytes written and rewrite ratio (administrator)
writehawk context               # display adapters, volumes, idle state, protected processes
writehawk fix <rule>            # show what a workaround would change; --apply to do it
writehawk rollback              # undo the newest change from its record
writehawk status                # changes this tool made and whether they still hold
writehawk report --out r.json   # everything as JSON, for a bug report or a script
writehawk watch install         # scheduled task that writes the report

Apply a workaround, and undo it

writehawk fix nvidia-nvtopps-log-rewrite            # prints the change, does nothing
writehawk fix nvidia-nvtopps-log-rewrite --apply    # administrator terminal
writehawk rollback --apply                          # puts everything back
  • A workaround is a short list of registry values. A catalog entry cannot run a command.
  • The prior state of every value is on disk before anything is changed, and undo works from that record alone.
  • Undo never overwrites a value that something else has changed since, unless you pass --force.
  • A workaround with a side effect is offered only where the side effect cannot bite.
  • The vendor's fixed driver is always the better answer. A workaround is for the time until you have it.

Why the fix did not just arrive

A vendor publishing a fix and your machine receiving it are separate events. A hotfix driver may be a manual download only. A fix may ship in an optional release while an older one stays recommended. A driver that came from Windows Update or the PC maker is not replaced by the vendor's own releases. writehawk checks which of these applies to your machine and says so.

Honest limits

  • It is early software. It is tested on Windows 11 and on Windows Server 2022, whose core is from the Windows 10 line. A Windows 10 desktop itself has not been run yet.
  • The two rules were checked against a replay of their write pattern, because the real bugs cannot be produced on demand.
  • Applying and undoing was verified on a scratch registry key and service in a disposable machine, not on a vendor's own service.

Everything that was and was not verified is written down in the research notes.
